# PerFin OS privacy data inventory

This inventory is repo-backed release evidence for App Store privacy labels, Google Play Data safety, policy copy, and reviewer notes. It describes current application code and configured repository dependencies only. Store-console answers still require final native build inspection and owner/legal review.

## Current dependency position

- Firebase is used for Authentication, Firestore, and App Check when signed-in features are configured.
- Cloudflare Worker routes broker protected receipt, place search, account deletion, and Plan requests.
- Google Places is called only through the protected Worker route.
- The configured AI provider is called only through the protected Plan Worker route after an explicit Plan request.
- No dedicated crash-reporting SDK is installed in `package.json`.
- No third-party product analytics SDK is installed in `package.json`.
- No push-notification or billing SDK is installed in `package.json`.
